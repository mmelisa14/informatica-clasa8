4Div, class și id: cele trei unelte de bază

Ca să spui CSS-ului pe cine să vopsească, ai nevoie de ele. Le cunoști pe rând:

📦div = o cutie
O cutie goală și invizibilă în care pui alte lucruri (text, poze, alte cutii), ca o ladă din Minecraft sau un Frame din Roblox. Nu face nimic singură: abia cu CSS o faci card, buton sau meniu. Poți pune cutii în cutii.
🏷️class = o etichetă de echipă
Pui class="bloc" pe oricâte elemente vrei. Apoi o singură regulă .bloc le schimbă pe toate, ca echipa roșie din Roblox care primește aceleași haine. În CSS se scrie cu punct în față.
🪪id = numele unic
Ca numele tău de jucător: doar un singur element îl are. În CSS se scrie cu #. Te ajută în două feluri: 1) stilizezi un singur element special; 2) JavaScript îl găsește după id ca să-l poată schimba (scorul, butonul, poza).

Exemplu: trei blocuri Minecraft. Toate au aceeași clasă bloc (deci aceeași formă), dar unul are și id="diamant" și iese în evidență:

💡 Un element poate avea și clasă, și id (ca diamantul de mai sus) și chiar mai multe clase, separate prin spațiu: class="bloc rar". Regula: id-ul nu se repetă în aceeași pagină, clasa se repetă oricât.

5Cutia: width, padding, border, margin

Fiecare div e o cutie cu straturi. Imaginează-ți un tablou (item frame) din Minecraft agățat pe perete: conținutul e obiectul din ramă, padding e spațiul gol dintre obiect și ramă, border e rama, margin e distanța până la următorul tablou. border-radius rotunjește colțurile. 📏 width măsoară doar conținutul. Lățimea totală pe ecran = width + padding (stânga și dreapta) + chenar (stânga și dreapta). Pentru cardul de mai jos: 220 + 20 + 20 + 4 + 4 = 268px.

8JavaScript: pagina prinde viață ⚡

Până acum pagina ta doar stătea frumoasă. JavaScript o face să reacționeze. Gândește-te la redstone: tragi o pârghie (eveniment), semnalul merge prin fire (codul), iar ușa se deschide (se schimbă ceva în pagină). Sau la Roblox: atingi o monedă și scorul crește.

🗃️Variabila
O cutie cu nume în care calculatorul ține o valoare, ca scorul sau monedele din joc.
🔎Găsirea elementului
JavaScript caută în pagină un element după id (aici vezi la ce ajută id-ul!) ca să-l poată schimba.
🕹️Evenimentul
„Când se întâmplă X, fă Y”: când se apasă butonul, crește scorul.
