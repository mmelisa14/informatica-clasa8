Learn what a spreadsheet is, how Excel looks, how to write formulas, and practice with a ready-made Excel file.

🔎 What is a spreadsheet?

A spreadsheet is a digital table where you can store numbers and text, and let the computer do the math for you.

In the past people used large paper sheets with rows and columns. Computers made it much better:

  • You can easily add or delete rows and columns.
  • You write formulas — when a number changes, the result updates automatically.
  • You control how numbers look (money, percent, date, etc.).
Example: You have grades for 15 subjects. If the average is calculated with a formula and you change one grade, the average recalculates instantly.

📗 Spreadsheet programs

The most popular ones:

  • Microsoft Excel — the most used (also Excel Online)
  • Google Sheets — free, works in the browser
  • LibreOffice Calc / OpenOffice Calc — free, installed on your computer

Excel files usually end with .xlsx.

🧱 Structure of an Excel workbook

Worksheet (sheet)

One table. Rows are numbered (1, 2, 3…) and columns have letters (A, B, C…). A sheet can have more than 1 million rows and 16 000 columns.

Cell

The small box where a row and a column meet. Example: cell B2 is column B, row 2.

Workbook

The whole Excel file. It can contain one or more sheets.

Range

Several cells next to each other. Written with a colon: D1:E2 means from D1 to E2.

🎛️ Main parts of the Excel window

  • Title bar — name of the file
  • Ribbon — all the buttons, grouped in tabs (Home, Insert, Formulas…)
  • Name Box — shows the address of the selected cell (e.g. B2)
  • Formula Bar — shows the real content of the cell (text, number or formula)
  • Worksheet area — the grid where you work
  • Sheet tabs — at the bottom; click to switch sheets; “+” adds a new sheet

🧮 Formulas — the most important part

Every formula starts with the equals sign =.

Example: =A1*B1 multiplies the value in A1 by the value in B1.

Basic operators

SymbolMeaningExample
+Add=A2+B2
−Subtract=A2-B2
*Multiply=A8*B8
/Divide=A8/B8
^Power=A2^3
Tip: Always use cell addresses (like A1) instead of fixed numbers. Then when you copy the formula, Excel automatically adjusts the row/column numbers.

Useful functions

AVERAGE — calculates the average
=AVERAGE(C4:F4) → average of cells C4, D4, E4, F4
SUM — adds numbers
=SUM(E4:E13) → sum of E4 to E13
IF — makes a decision
=IF(G4>=5,"Promoted","Failed")
If G4 is 5 or more → show “Promoted”, otherwise show “Failed”
MAX / MIN — biggest / smallest value
=MAX(G4:G15)   =MIN(G4:G15)
COUNTIF — count cells that meet a condition
=COUNTIF(G4:G15,">=8") → how many averages are ≥ 8
Number formats: General, Currency, Percentage, Date, Text…

📋 How to copy a formula down a column

  1. Write the formula in the first cell (e.g. G4).
  2. Press Enter.
  3. Click the cell again. Look for the small square in the bottom-right corner (fill handle).
  4. Drag it down to the last row you need.
  5. Excel copies the formula and changes the row numbers automatically.

🎨 Conditional Formatting

Excel can automatically color cells based on their value.

  1. Select the range of cells (e.g. the grades).
  2. Go to Home → Conditional Formatting → Highlight Cells Rules.
  3. Choose “Greater Than or Equal To” 9 → green fill.
  4. Choose “Less Than” 5 → red fill.

📈 Charts (graphs)

A chart helps you see the data quickly. Steps:

  1. Select the data (including headers).
  2. Go to Insert → Charts.
  3. Pick a type: Column, Bar, Line, Pie, etc.
  • Column / Bar — compare values between categories
  • Line — show a trend over time
  • Pie — show parts of a whole (percentages)

🎯 Quick recap

  • A formula always starts with =
  • =AVERAGE(...) → average
  • =SUM(...) → sum
  • =IF(condition, "yes", "no") → decision
  • =MAX(...) / =MIN(...) → highest / lowest
  • =COUNTIF(range, ">=8") → count with condition
  • Drag the fill handle to copy formulas
  • Conditional Formatting colors cells automatically
