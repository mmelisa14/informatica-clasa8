Using Spreadsheets

Discover what a spreadsheet is, what the Microsoft Excel window looks like, what you can do with formulas and functions, how to build charts — and practise with a ready-made Excel file.

🔎 What is an electronic spreadsheet?

A way to manage data organised as a table. The name comes from accounting, where large paper forms with horizontal and vertical lines were used.

Computers brought huge advantages over paper:

  • you can easily build a table — insert or delete rows and columns at any time;
  • besides typed values, you can add calculation formulas that update automatically;
  • you control exactly how values are displayed (currency, percent, date, etc.).

Example: a table with 15 subjects and 5 grades each. If each subject's average is calculated by a formula and you change a single grade, that subject's average — and the overall average — recalculates instantly, with no manual work.

Notice the two "rulers", like in chess: numbers for rows, letters for columns. The cell with "TIC" is A14 and the overall average is in G18.

Spreadsheet programs

Applications made for working with spreadsheets are called spreadsheet programs. The most popular: 📗 MS Excel / Excel Online · 📘 LibreOffice Calc · 📙 OpenOffice Calc · 📕 WPS Spreadsheets · 📓 Ashampoo PlanMaker · 📈 Google Sheets

LibreOffice Calc — free, installed locally, available in many languages. OpenOffice Calc — part of the free Apache OpenOffice suite.

Each has pros and cons: MS Excel is the most popular, so help is easy to find; Calc and Spreadsheets are free; some are installed on your computer (work offline), others are online (use no storage space, but need internet).

📗 Microsoft Excel

MS Excel (or simply Excel) is the best-known spreadsheet program, part of Microsoft Office. An Excel file can have the extension .xls, .xlsx or .xlsm.

Start it like Word: Start → All Apps → Excel, or type "Excel" in the Windows search bar and press Enter. A start screen lets you choose:

  1. Blank workbook — start from scratch;
  2. a template — a ready-made model;
  3. open an earlier workbook — from the recent list or from the cloud (OneDrive).

🧱 Structure of a workbook

📄 Worksheet
One table. Rows are labelled with numbers (1, 2, ...) and columns with letters (A, B, ...) — up to 1,048,576 rows and 16,384 columns.
🔲 Cell
The basic unit of the table, at the intersection of a row and a column. Its name is column + row, e.g. B2.
🗂️ Workbook
The file created with Excel, made of one or more worksheets.
🔳 Range
Several adjacent cells. It is written with the top-left and bottom-right corners separated by ":", e.g. D1:E2 or G2:I2.

Parts of the Excel window

A new workbook is automatically named "Book1", not yet saved. The window has:

  • A – Title bar — workbook name, Microsoft search, user account, minimise/maximise/close buttons.
  • B – Ribbon — all Excel commands, grouped in tabs.
  • C – Name Box — shows the name of the current cell (here B2, with a green border).
  • D – Formula Bar — shows the real content of the selected cell (text, number or formula).
  • E – Work area — the worksheet itself, with rows and columns.
  • F – Sheet tab — the name of the current sheet (default "Sheet1").
  • G – Add sheet button.
  • H – View mode: Normal, Page Layout or Page Break Preview.
  • I / J – Vertical / horizontal scroll bars.
  • K – Zoom — +/− buttons, slider and current percentage.

🎛️ The Ribbon

It holds all Excel commands, grouped in tabs by type of action. A tab has logical groups of commands, and each group has individual buttons. A small arrow in the bottom-right corner of a group opens more options.

1 – Ribbon tabs · 2 – individual commands · 3 – command groups · 4 – ribbon display options: Full-screen mode, Show tabs only, Always show Ribbon.

File tab — Backstage

Opens the special Backstage view with all actions on the file: create, open, save, export, share, print, close.

Home tab

Basic commands for editing and formatting cells.

  • Clipboard — Paste, Copy, Cut, and Format Painter (copies the format of one cell to another).
  • Font — font type and size, Bold/Italic/Underline, text colour, Fill Color, borders.
  • Alignment — horizontal/vertical alignment, wrap text, merge cells.
  • Number — cell format: General, Currency, Percent, decimals (see "Data types").
  • Styles — Conditional Formatting (highlights values automatically by a rule), Format as Table, Cell Styles.
  • Cells — Insert/Delete rows and columns, Format (row height, column width).
  • Editing — AutoSum (Σ), Fill, Sort & Filter, Find & Select.
  • Add-ins — extensions installed for Excel.

Insert tab

Adds new content to a worksheet.

  • Tables — PivotTable / Recommended PivotTables (interactive summary tables), simple Table.
  • Illustrations / Controls — pictures, shapes, icons; Checkbox for tick lists.
  • Charts — recommended charts, all chart types, Maps, PivotChart (see "Charts").
  • Sparklines — mini-charts ("Line", "Column", "Win/Loss") that fit in a single cell.
  • Links / Filters — hyperlinks to web pages or other sheets; slicers.
  • Text / Symbols — text box, WordArt; special symbols and characters.

Draw tab

Drawing, highlighting and handwritten notes — mostly useful on touch screens. The Ink to Math button recognises a handwritten formula and turns it into text.

Page Layout tab

Set up how pages look and how large tables are arranged when printed.

  • Themes — matching Colours, Fonts and Effects in one click.
  • Page Setup — Margins, Orientation (Portrait/Landscape), Size, Print Area, Breaks, Background, Print Titles.
  • Scale to Fit — Width, Height and Scale: a big table can fit on one printed page.
  • Sheet Options — Gridlines and Headings (view and/or print).
  • Arrange — position objects (pictures, shapes) relative to cells.

Formulas tab

All the tools for writing and checking calculation formulas.

  • Function Library — Insert Function, Financial, Logical, Text, Date & Time functions, grouped by category.
  • Defined Names — give a name to a cell/range (e.g. "VAT") and use it in formulas instead of the cell address.
  • Formula Auditing — Trace Precedents shows which cells affect the current cell; Trace Dependents shows which cells it affects. Great for understanding or fixing a complex table.
  • Calculation — automatic or manual calculation options, for very large workbooks.

Data tab

Working with the data in the sheet: sorting, filtering, splitting text into columns.

  • Get & Transform Data — import data from other files or external sources.
  • Queries & Connections — manage links to other workbooks.
  • Sort & Filter — Sort ascending/descending (by one or more criteria), Filter to show only certain rows.
  • Data Tools — Text to Columns splits one column (e.g. full name) into several (first name + last name).
  • Forecast — What-If Analysis, Forecast Sheet: estimate future values from existing data.

Review tab

Spell check, comments, password protection.

  • Proofing — Spelling, Thesaurus, Workbook Statistics.
  • Accessibility / Insights — checks how easy the workbook is to use; Smart Lookup on the internet.
  • Language — translate the text in cells.
  • Comments / Notes — add remarks on cells, visible to collaborators.
  • Protect / Ink — password-protect the sheet/workbook; hide ink annotations.

View tab

How the worksheet is displayed on screen.

  • Workbook Views — Normal, Page Layout, Page Break Preview (useful before printing).
  • Show — Ruler, Gridlines, Formula Bar, Headings: show/hide helper tools.
  • Zoom — enlarge/shrink the visible area; Zoom to Selection.
  • Window — New Window, Arrange All, Freeze Panes (keeps the header visible while scrolling), Switch Windows.
  • Macros — automate repeated actions recorded as a sequence of steps.

Help tab

The last tab: find information on using the program and send feedback to Microsoft.

Also, the Share tab (top-right) allows collaborative work on the same workbook if it is saved in the cloud.

📁 Basic operations with a workbook

Like in any office application — create, open, save, print, close.

  • Create — Blank workbook from the start screen, or File → New, or Ctrl+N.
  • Open — File → Open or Ctrl+O.
  • Save — Save (Ctrl+S) keeps the name/format; Save As (F12) changes the name, type or location.
  • View — Normal, Page Layout or Page Break Preview, from the View tab.
  • Print — File → Print, on a real printer or into a .pdf file.
  • Close — File → Close or the button in the top-right corner.

Operations with worksheets

  • Rename — double-click the sheet tab, then type the new name.
  • Create (insert) a new sheet — the "+" button next to the sheet tabs.
  • Go to a sheet — a single click on its tab.
  • Change the order — drag the tab to the place you want.
  • Delete — right-click the tab → Delete.
  • Move or Copy... — right-click the tab; you can choose the workbook, the position, and whether you want a copy.

🎨 Formatting a workbook

You can format rows and columns, and also cells — depending on the information they contain.

a. Formatting rows and columns

Place the mouse on the line between two column letters. The cursor becomes a vertical line with two arrows — hold and drag to make the left column narrower or wider. Double-click that line to automatically fit the width to the text. Do the same for row height, on the line between the row numbers.

The same multiplication table by 6: default columns, narrower columns, and taller rows.

b. Formatting cells

Excel has predefined cell styles (Home → Styles → Cell Styles), but you can also create your own formatting. Right-click a cell → Format Cells... opens a window with several tabs:

Alignment tab Font tab
  1. Horizontal/vertical alignment of text (left, centre, right, top, bottom, etc.).
  2. Text control: Wrap text (on several lines), Shrink to fit, Merge cells.
  3. Orientation — text can be horizontal, vertical or slanted (angle in degrees).
  4. From the Font tab: effects — strikethrough, superscript, subscript.
  5. Font, style (regular/italic/bold), size and text colour.
Border tab — style, line colour and where it applies (outline/inside). Fill tab — the cell's background colour, with a "More Colors..." button for extra shades.

You can freely combine all these options: a cell can be bold, centred, with a yellow background and a double border at the same time.

🔢 Data types: number, text, date and others

Maybe the most important formatting option in practice is that you can set a cell's content to be of a certain type.

  • Number — set the thousands separator and the number of decimals shown.
  • Currency — different currencies, including RON.
  • Date or time — allows operations (adding/subtracting) with dates and times.
  • Percentage — the value 0.25 is shown as 25%.
  • Fraction — if you type "5.5", it shows "5 1/2".
  • Text — the content is treated as a string of characters, not as a number.
Number tab in Format Cells — categories of data types.

🧮 Calculation formulas

The main purpose of a spreadsheet is to get automatically calculated results, based on formulas. A formula always starts with the = sign. Example: =A1*B1 multiplies the content of cell A1 by the content of B1.

Arithmetic operators

  • + and − — add / subtract. Ex: =A2+B2
  • * and / — multiply / divide. Ex: =A8*B8
  • ^ — power. You can also use brackets, with the same priority as in maths.

A key advantage: if you write the formula with cell references (=A1*B1) instead of fixed values (=1*6) and copy it to another cell, Excel adapts the formula to the new row automatically. You can even drag the bottom-right corner of the cell to copy the formula over a whole table.

Complex expression: =((A1+A2)*(A4-B4))/((A8*B8)+(A11/B11))

Basic functions

SUM — sum
=SUM(number1, [number2], ...)
Adds single values, cells or whole ranges.
=SUM(A2:A10) → adds A2 to A10
AVERAGE — arithmetic mean
=AVERAGE(number1, [number2], ...)
=AVERAGE(A2:A10) → average of A2 to A10
MAX / MIN
=MAX(...) / =MIN(...)
Return the largest / smallest value in a set.
=MAX(A2:A10)
IF — decision
=IF(logical_test, value_if_TRUE, value_if_FALSE)
Compares a value with a condition and returns one of two results.
=IF(D4>=80,"PASSED","FAILED")

Other very useful functions

COUNT — counts cells with numbers
=COUNT(range) — ignores text and empty cells.
=COUNT(C2:C11) → how many grades are entered
COUNTA — counts non-empty cells
=COUNTA(range)
=COUNTA(A2:A20) → how many students are in the list
COUNTIF — counts with a condition
=COUNTIF(range, criteria)
=COUNTIF(C2:C11,">=9") → how many grades are ≥ 9
SUMIF — sum with a condition
=SUMIF(test_range, criteria, [sum_range])
=SUMIF(B2:B11,"Milk",D2:D11) → total spent only on "Milk"
ROUND
=ROUND(number, decimals)
=ROUND(9.847,1) → 9.8
MOD — remainder of a division
=MOD(number, divisor)
Useful to test if a number is even/odd or divisible. =MOD(10,3) → 1

Functions can be combined with each other and with operators, e.g. =SUM(B1,B2)*MIN(C1,C2,C3)/MAX(C4,C5) or =IF(COUNTIF(C2:C11,"<5")>0,"Has failing grades","All grades are passing")

📈 Charts

A chart helps you understand at a glance what is in your table. Make it in 4 steps: build the data table → select it → Insert tab → Charts group → choose the right type. A chart updates automatically if you change the data it was made from.

Which chart to choose?

📊 Column / Bar

Compare values between a few categories (grades per subject, sales per product).

📉 Line

Show a trend over time or in stages (progress, growth, decline).

🥧 Pie / Doughnut

Show the proportions of a whole: what percent each part represents.

⚫ Scatter (XY)

Check whether there is a connection (correlation) between two sets of numbers.

Interactive examples

Four real situations with live charts built on the page. Explore them, then read the interpretation.

📊 Book genres borrowed from the school library

Interpretation: Adventure and Fantasy clearly lead with over 40 books each, while Poetry barely passes 10. A bar chart instantly shows which genres to buy more of in the next order.

📉 Visitors on the class website in one week

Interpretation: Traffic grows steadily towards the weekend, with a peak on Saturday. A line chart highlights the trend — students visit mostly when they have no classes.

🥧 How Andrei spends his free time on a normal day

Interpretation: Screens (phone + computer) take almost a third of his free time — more than sports and hobbies together. A pie/doughnut chart shows this imbalance much faster than a table of percentages.

⚫ Study hours vs. grade obtained

Interpretation: The points rise from left to right — the more a student studied, the higher the grade. It is not a perfect rule (see the isolated point at 5 hours / grade 6), but the general trend is clear. Excel offers this under "XY Scatter".
